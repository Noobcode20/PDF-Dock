# PDF Dock 0.1.0-beta.6

This beta integrates the pending editor, shortcuts, onboarding, feedback, and CLI work with the current desktop release.

- Stabilize continuous scrolling across pages with different dimensions: fitting no longer changes zoom as the visible page changes; virtual geometry owns scroll anchoring.
- Keep rapid page navigation protected while page geometry settles.
- Restore normal Select-mode layering so image hit areas do not intercept text and form widgets.
- Bound preview raster memory and load local fonts without unnecessary duplication.
- Download the specific offered macOS beta instead of using GitHub's stable-only latest URL.
- Keep beta updates forward-only, with download progress, skip persistence, and manual macOS installation.
- Patch the bundled image-size parser; the production dependency audit reports zero known vulnerabilities at release preparation.
- Run regression tests before either platform's installers can be published.

Validation includes the complete Node regression suite, the Vite production build, native text editing/export/reopen checks, and a dedicated Electron regression for long-document rendering, page navigation, scrolling, and narrow layouts. See the release PR for final runtime results.

Distribution remains a beta: macOS builds are not Developer ID signed or notarized. Windows installers are built by GitHub Actions; Windows installer execution and an end-to-end installed Windows update are not validated on this Mac. OCR models may require a first download. These checks do not establish correctness for every possible PDF.
